# FER2013 主流做法调研与本项目对比

> 目的：调研学界/社区在 FER2013 上的数据划分与算法思路，与本项目当前方案对比，找出差距与可落地的改进点。
> 本项目当前结果：测试集 **Accuracy 0.567 / Macro-F1 0.538**（轻量 3 层 CNN，约 115 万参数）。

---

## 1. FER2013 数据集本质与公认难点

- 规模：35,887 张 48×48 灰度人脸，7 类（angry/disgust/fear/happy/neutral/sad/surprise）。
- **人类准确率仅约 65.5%**：这是数据集的"天花板"。简单 CNN 普遍 55–65%，单模 SOTA 约 73%，集成 SOTA 约 75%。
- **标签噪声大**：图片来自网络爬取 + 众包标注，存在错标、重复、非人脸样本。
- **类别极不平衡**：`disgust` 仅占 ~1.5%（547 张），`happy` 占 ~25%。
- **类间易混**：`disgust` vs `angry`、`fear` vs `sad/surprise` 区分度低——这与我们混淆矩阵中
  `fear`（F1 0.32）最差、`disgust` 被过度预测的现象完全吻合。

---

## 2. 数据划分：标准约定 vs 本项目

FER2013 原始数据每张图带 `Usage` 字段，**学界标准三分法**：

| 子集 | 文件名前缀 | 数量 | 标准用途 |
|---|---|---|---|
| Training | `Training_*` | 28,709 | 训练 |
| PublicTest | `PublicTest_*` | 3,589 | **验证**（调参） |
| PrivateTest | `PrivateTest_*` | 3,589 | **测试**（最终报告精度，论文都报这个） |

**本项目当前划分**（与标准不同，需注意）：
- 我们的 `datasets/test/` = PublicTest 3589 + PrivateTest 3589 = **7178 张混在一起**。
- 我们从 `train` 里**随机切 10%** 当验证集，最后在 7178 张合并集上报 0.567。

> ⚠️ 影响：我们的 0.567 是在 Public+Private **合并集**上算的，**不能直接和论文的 PrivateTest 数字（如 73%）对标**。
> 想严格对齐学界，应按文件名前缀把 PublicTest 划为 val、PrivateTest 划为 test，只在 PrivateTest 报精度。

## 3. 主流算法路线与精度对比

| 方法 | 测试精度(PrivateTest) | 关键点 |
|---|---|---|
| 简单自定义 CNN（社区常见） | ~64–66% | 几层 Conv+BN+Dropout，和我们结构同档 |
| **本项目（3 层 CNN）** | **0.567（合并集）** | 见上，划分口径不同，实际同档偏低 |
| 单模 VGG（精调超参） | **73.28%** | VGGNet + 仔细调参 + 优化器实验（当前单模 SOTA） |
| VGG 从零训练 | ~67% | 从零训练优于直接迁移微调 |
| ResNet18 + Random Erasing + FER+ 标注 | **76.71%** | 随机擦除增强 + 干净标签 |
| 现代深 CNN **集成(ensemble)** | **75.2%** | 多模型投票，无需额外数据/人脸对齐 |
| EfficientNet-B2 | 70%+ | 轻量高效骨干 + ImageNet 预训练 |

**结论**：从 56.7% 到 65%+ 的差距，主要不在"换更大模型"，而在**训练技巧、数据增强、标签质量、评测口径**。

---

## 4. 主流训练技巧清单（我们尚未用的）

1. **更强数据增强**：Random Erasing / Cutout（随机遮挡，公认对 FER2013 提升明显，是 76.71% 方案的关键）、
   RandomResizedCrop、轻微仿射。仅用翻转+小旋转（我们当前）偏弱。
2. **Ten-Crop 测试增强（TTA）**：测试时把图裁成 10 个角/翻转分别预测再平均，普遍 +1~3%。
3. **Label Smoothing**：缓解标签噪声 + 抑制过度自信（正好对应我们 val-loss 回升、val-acc 仍升的现象）。
4. **预训练迁移**：用 ImageNet 预训练的 VGG/ResNet/EfficientNet 骨干，再微调。
5. **FER+ 重标注**：用众包多投票的更干净标签替换原标签，单这一项就能显著提分。
6. **更好的学习率策略**：Cosine Annealing / warmup + AdamW，替代我们当前的 StepLR。
7. **模型集成**：多个模型/多次训练投票，集成 SOTA 75.2% 的核心手段。
8. **处理不平衡的更优做法**：Focal Loss、或对 disgust 做过采样/CycleGAN 合成，
   而不是单纯加大权重（我们给 disgust 权重 9.4，导致它被过度预测、精度仅 0.35）。

## 5. 本项目方案 vs 主流：逐项对比

| 维度 | 本项目当前 | 主流/SOTA 做法 | 差距 |
|---|---|---|---|
| 模型 | 3 层 CNN(valid 卷积) ~115 万参 | VGG/ResNet18/EfficientNet | 容量偏小 |
| 预训练 | 无（从零） | 多用 ImageNet 预训练 | ★ |
| 数据增强 | 翻转 + ±10°旋转 | + Random Erasing/Cutout, RandomCrop | ★★ |
| 测试增强 | 无 | Ten-Crop TTA | ★ |
| 损失 | 加权 CrossEntropy(权重9.4) | Label Smoothing / Focal Loss | ★★ |
| 不平衡 | 逆频率类别权重 | 过采样/合成/Focal | ★ |
| 标签质量 | 原始 FER2013(含噪声) | FER+ 重标注 | ★★ |
| LR 策略 | StepLR | Cosine + warmup, AdamW | ★ |
| 集成 | 单模 | 多模型 ensemble | ★（成本高） |
| 评测口径 | Public+Private 合并 | 仅 PrivateTest | 口径需对齐 |
| 存档指标 | 按 val-loss（存到了 epoch32） | 通常按 val-acc | 小漏洞 |

## 6. 针对本项目的改进建议（按性价比排序）

| 优先级 | 改进 | 预期收益 | 成本 |
|---|---|---|---|
| P0 | 评测口径对齐：按前缀分 PublicTest=val / PrivateTest=test | 数字可信、可对标 | 改数据加载 |
| P0 | 存档/早停改为按 **val-acc**（兼存 best-loss / best-acc） | +1~2% | 几行 |
| P0 | 类别权重改 `sqrt(逆频率)` 或换 **Label Smoothing** | 修复 disgust 过预测、稳住 macro-F1 | 1~2 行 |
| P1 | 加 **Random Erasing + RandomCrop** 增强 | +2~4% | 改 transform |
| P1 | **Cosine LR + warmup**，多训几十 epoch | +1~3% | 改 scheduler |
| P2 | 换 **预训练 ResNet18/EfficientNet** 骨干微调（输入转3通道/resize） | +5~10% | 改 model |
| P2 | **Ten-Crop TTA** 测试增强 | +1~3% | 改 eval |
| P3 | 用 **FER+** 干净标签重训 | 显著 | 需下载额外标注 |
| P3 | 多模型 **集成** | +1~3% | 训练成本高 |

> 对课程项目而言：做完 **P0 三项 + P1 两项**，本架构有望从 0.567 提升到 **0.63~0.66**，
> 接近"简单 CNN"的合理水平；若要冲 70%+，需上 P2（预训练骨干）。
