# 基于视频流的面部表情识别（FER）· 项目综合报告

> 对象：DIP 课程项目，FER2013 + OpenCV 摄像头实时推理（2–3 人 / 15 天）。
> 路线：先做了一版轻量 3 层 CNN（基线），再按本报告的方案做了系统性优化与创新升级。
> **实测成绩**：基线 3 层 CNN —— 旧口径(Public+Private 合并) Acc **0.567** / Macro-F1 0.538；
> 升级后预训练 ResNet18 —— 严格 PrivateTest 口径 Acc **0.660** / Macro-F1 **0.629**。
> 立场：务实、对标真实行业、不堆套话。定位校准——这是课程作业，不是毕设、更不是产品，所有"短板/风险"都按这把尺子量。

**全文结构**：一 背景与定位 → 二 基线架构与底层算法 → 三 FER2013 难点与学界对标 → 四 改进方案（已实施，逐项可解释）→ 五 改进后实测闭环 → 六 现存短板与潜在风险 → 七 市场痛点与落地可行性 → 八 前沿优化与跨场景落地 → 九 总结 → 附 参考来源。

## 一、项目背景：它到底在解决什么、处在什么位置

把这个项目剥到底，它是两件事拼起来的：

1. **一个标准的 FER2013 图像分类任务**——48×48 灰度人脸，分 7 类情绪，计算机视觉里被刷了十年的"老题目"。
2. **一个经典 DIP 流水线的实时落地**——灰度化、直方图均衡、Haar 人脸检测、缩放归一化，再接 CNN 推理，套在 OpenCV 摄像头逐帧上。

第二点才是这门课（数字图像处理）真正想考的东西。CNN 某种程度上是"配角"——课程核心是把灰度变换、均衡、级联检测这些**经典图像处理算子**串成一条能跑的管线。这决定了评判标准：**价值不在于精度刷多高，而在于管线是否完整、原理是否吃透、工程是否跑通。**

选型务实：FER2013 公开、体量适中（3.5 万张）、48×48 小图对算力友好，Haar + CNN 是教科书级稳妥组合，没为炫技上 Transformer——15 天窗口里这是对的。

## 二、基线版本：原始架构与底层算法（逐层拆解）

> 这一节描述**优化前的初版**，是后续所有改进的对照基准。

### 2.1 数据与预处理

**双路径**结构（设计得不错）：
- **训练/评估路径**：torchvision transforms 在线变换。训练 `Grayscale → EqualizeHist → 翻转 → ±10°旋转 → Resize → ToTensor`；评估去掉随机增强保可复现。
- **摄像头路径**：`preprocess_face()` 走完整经典 DIP——`cvtColor` 灰度化 → Haar `detectMultiScale` 检测 → `equalizeHist` 均衡 → `resize` 48×48 → `/255` 归一化。

底层算法：**直方图均衡**= 把灰度 CDF 拉成近似均匀分布提对比度；**Haar 级联**= Viola-Jones（Haar 特征 + 积分图 + AdaBoost）。数据集本身已是裁好的灰度脸，故训练路径上灰度化/检测基本是空操作，**Haar 只在摄像头帧才真需要**——代码注释里写明了，认知清醒。

### 2.2 模型

三个 `[Conv3×3(valid) + BN + ReLU + MaxPool]` 块，通道 1→32→64→128，空间 48→23→10→4，展平 128×4×4=2048，接 `FC(2048,512) + Dropout(0.5) + FC(512,7)`，约 115 万参数。
- **valid 卷积(padding=0)** 每层丢边缘一圈像素，48×48 小图三层下来损失不小、空间压到 4×4 偏紧。
- BN + Dropout 0.5 的正则配置合理。

### 2.3 训练

ImageFolder 加载 → `random_split` 切 10% 验证集 → 分别套增强/非增强变换（"先切后套"避免验证集被污染，干净）；逆频率类别权重（disgust 被抬到 ~9.4）；Adam lr=1e-3 + StepLR；50 epoch，patience=10；**按 val_loss 存档**。

### 2.4 评估与 Demo

评估输出 Accuracy / Macro-F1 / 分类报告 / 混淆矩阵，规范完整；Demo 逐帧推理画框+标签+置信度，标注了 WSL2 摸不到摄像头要在 Windows 跑。**train/eval/demo 不互相 import，全靠 `best.pth` 里的 `class_to_idx` 解耦**——成熟习惯。

### 2.5 基线实测与自我诊断

基线 3 层 CNN 实测 **Acc 0.567 / Macro-F1 0.538**（旧口径），并诚实画出混淆矩阵定位到 **fear（F1 0.32）最差、disgust 被过度预测（precision≈0.35）**。难得的是团队主动做了学界调研（见第三节）、**自己揪出了评测口径问题**——这种自我审视比虚假"创新点"有价值。

## 三、FER2013 的本质难点与学界对标

理解改进空间，先得知道这个数据集有多"病态"和别人做到哪了。

### 3.1 数据集本质

- 规模 35,887 张 48×48 灰度脸，7 类。
- **人类标注一致性仅 ~65.5%**——这是数据集的"天花板"，连人都常分不清 fear / surprise。简单 CNN 普遍 55–65%，单模 SOTA ~73%，集成 SOTA ~75%。
- **标签噪声大**：网络爬取 + 众包标注，有错标、重复、非人脸样本。
- **类别极不平衡**：disgust 仅 ~1.5%（547 张），happy ~25%。
- **类间易混**：disgust↔angry、fear↔sad/surprise——与混淆矩阵现象完全吻合。

### 3.2 标准数据划分（评测口径的根）

FER2013 每张图带 `Usage`，文件名前缀区分：

| 子集 | 前缀 | 数量 | 标准用途 |
|---|---|---|---|
| Training | `Training_*` | 28,709 | 训练 |
| PublicTest | `PublicTest_*` | 3,589 | 验证/调参 |
| PrivateTest | `PrivateTest_*` | 3,589 | **测试（论文都报这个）** |

> 基线把 Public+Private 合并成 7178 张当 test，所以 0.567 **无法与论文对标**——这是首个必修项。

### 3.3 主流算法路线与精度

| 方法 | PrivateTest 精度 | 关键点 |
|---|---|---|
| 简单自定义 CNN（社区常见） | ~64–66% | 与基线同档 |
| 单模 VGG（精调） | **73.28%** | 当前单模 SOTA |
| VGG 从零训练 | ~67% | 优于直接迁移微调 |
| ResNet18 + Random Erasing + FER+ 标注 | **76.71%** | 随机擦除 + 干净标签 |
| 现代深 CNN 集成 | **75.2%** | 多模型投票 |
| EfficientNet-B2 | 70%+ | 轻量骨干 + 预训练 |

**结论**：从 56.7% 到 65%+ 的差距，主要不在"换更大模型"，而在**训练技巧、数据增强、标签质量、评测口径**——这正是第四节改进方案的依据。

## 四、改进方案（已实施，逐项可解释）

> 本次按"可信度优先 → 性价比提分 → 创新升级"三档落地，每项都能讲出原理（满足 DIP 课"可解释"要求）。涉及文件已全部改造完成。

### 4.1 修"可信度"（评测与训练目标）
- **评测口径对齐**：`eval.py` 新增 `--split private/public/all`，按文件名前缀筛选，默认只在 **PrivateTest** 报数，数字可与论文对标。
- **按 val_acc 存档**：早停/存档从监控 val_loss 改为 **val_acc**（兼存 best_loss）。加权损失的 val_loss 最优点常与分类最准点错开，改后直接对齐分类目标。

### 4.2 提分（损失 / 增强 / 优化 / 结构）
- **sqrt 逆频率权重 + Label Smoothing(0.1)**：把过猛的线性逆频率(disgust×9.4)换成更温和的 `sqrt`，叠加标签平滑缓解标签噪声、抑制过度自信——直接治"disgust 过度预测"。
- **CLAHE 替代全局均衡**：限制对比度的自适应分块均衡，增强局部对比的同时不放大平坦区噪声，更适合人脸。
- **Random Erasing + RandomResizedCrop**：随机遮挡 + 随机缩放裁剪，FER2013 上公认涨点的增强，抗遮挡/尺度抖动。
- **AdamW + 线性 warmup + 余弦退火**：替代 Adam+StepLR，正则更干净、学习率曲线更平滑。
- **卷积 padding=1 + 自适应池化**：保留边缘信息，并用 `AdaptiveAvgPool2d((4,4))` 稳定全连接输入维度。

### 4.3 创新升级（含可解释性一等公民）
- **预训练 ResNet18 骨干（可选 `--arch resnet18`）**：迁移学习。单通道 conv1 由 ImageNet 的 RGB 权重按通道平均迁移，其余层全部沿用预训练，最大化保留先验。
- **Ten-Crop TTA（`--tta`）**：10 视角预测平均，等价小型集成（注：本数据集上无增益，见 5.4）。
- **时序滑动投票（Demo）**：IoU 跟踪关联同一张脸 + 最近 N 帧 softmax 平均投票，等于对预测做低通滤波，消除标签跳变——**真正兑现"视频流"而非逐帧独立**。
- **Grad-CAM 可解释性**（核心创新点）：纯数学、无需额外训练，画出"模型看脸上哪块"做判断，把黑箱变成可见证据。`eval/visualize_cam.py` 一键生成每类样本的热力图网格。

## 五、改进后 · 实测结果闭环（2026-06）

> 用 **预训练 ResNet18** 实训，严格在 **PrivateTest（3589 张）** 口径评估，形成"分析 → 改造 → 实测"完整闭环。

### 5.1 总体指标

| 口径 | 模型 | Accuracy | Macro-F1 |
|---|---|---|---|
| 旧（Public+Private 合并 7178） | 基线 3 层 CNN | 0.567 | 0.538 |
| **新（仅 PrivateTest 3589，可对标论文）** | **预训练 ResNet18** | **0.660** | **0.629** |

> 两行口径不同，不能直接相减；0.660 是首个"可与论文对标"的成绩，落在 ResNet18 合理区间（0.67~0.73）的下沿。

### 5.2 逐类 F1（PrivateTest）

| 类别 | F1 | 说明 |
|---|---|---|
| happy | 0.864 | 最强 |
| surprise | 0.737 | 强 |
| neutral | 0.631 | 稳 |
| angry | 0.609 | 可 |
| disgust | 0.554（P 0.544 / R 0.564） | **过度预测已修复**（旧 P≈0.35） |
| sad | 0.535 | recall 高、precision 偏低，成了"吸铁石"类 |
| fear | 0.475 | 仍最弱，主要混入 sad —— FER2013 固有难点 |

### 5.3 各改进项的实测验证
- **口径对齐**：已只在 PrivateTest 报数，数字可信。✔
- **sqrt 权重 + Label Smoothing**：disgust 由 P≈0.35 修复为 P 0.54 / R 0.56，类别均衡明显改善，macro-F1 站稳 0.63。✔
- **预训练 ResNet18**：相对基线在对齐口径下实现质的提升。✔
- **Grad-CAM**：热力图集中在五官表情区（嘴角/眉眼/脸颊），未落到背景/头发，证明学到的是真表情特征。✔（ResNet layer4 空间分辨率低、CAM 呈大色块属正常）

### 5.4 诚实记录：TTA 无增益
**Ten-Crop TTA 在本数据集上未带来提升**（0.6595 → 0.6595，逐格一致）。原因：FER 人脸仅 48×48 且已裁正，小幅裁剪制造不出视角差异，Ten-Crop 在此天然失效——属数据特性，非实现缺陷。保留接口但不依赖它。

## 六、现存短板与潜在风险（改进后状态）

### 6.1 仍存在的短板
- **后期过拟合**：train acc≈0.83 vs val acc≈0.63（差 ~0.20）。已靠"按 val_acc 存档"锁定最优点；要冲 0.68~0.70 应**对症抗过拟合**（加大 weight decay、冻结浅层、更强增强），而非训更久。
- **fear / sad / neutral 互混**：标签噪声 + 类间相似的固有难点，缓解到位、难以根除。
- **Haar 检测脆弱**：frontalface 级联只认正脸，侧脸/低头/口罩/暗光漏检——实时管线的薄弱环节。

### 6.2 潜在风险
- **技术**：精度被数据集天花板（人类 65.5%）锁死，堆模型边际递减；Haar 漏检导致实时"断流"。
- **结论**：对外只能说 0.660，且必须讲清是 PrivateTest 口径；不可与他人的合并集数字混比。
- **复现**：`random_split` 的 val 来自 train，FER2013 已知有重复图，验证精度可能略偏乐观。
- **伦理/合规**（一旦想落地）：情绪识别的科学争议 + 法规收紧，悬在所有 FER 应用头上。

## 七、市场痛点与落地可行性

### 7.1 真实行业痛点
1. **数据集天花板就是地板**：人类一致性 ~65.5%，70%+ 已近极限——不是模型不够大，是**任务本身病态**。
2. **实验室 vs in-the-wild 鸿沟**：真实摄像头要面对极端光照、遮挡、姿态、肤色/文化差异，FER2013 上 70% 的模型换真实场景可能掉到 40%。
3. **科学有效性争议（最致命）**：心理学界（Barrett 等）质疑"基本情绪理论"——**皱眉≠生气、微笑≠开心**，表情与内在情绪并非可靠映射。
4. **隐私合规**：人脸+情绪是敏感生物特征，欧盟 AI Act 已把"职场/教育情绪识别"列入高风险甚至禁用。

### 7.2 可行性分级
- **课程交付**：✅ 完全可行，完成度中上——能跑、有评测、有调研、有改进闭环、有可解释证据，拿高分没问题。
- **Demo / 毕设原型**：🟡 可行，已补齐口径对齐 + 时序平滑 + 0.66 单模；再往上可上关键点融合/连续 V-A。
- **产品**：❌ 不可行。四大痛点每条都是产品级硬约束，不是改代码能解决的。

## 八、前沿优化与跨场景落地（面向未来）

### 8.1 把项目继续"现代化"（前沿方向）

- **A1 骨干**：越过自定义 CNN，主力是 **POSTER/POSTER++**（关键点 × 图像特征交叉注意力）、**DAN/MA-Net**。轻量中间路线：把 Haar 升级成 **MediaPipe/RetinaFace 468 点关键点**，几何特征 + CNN 特征拼接。
- **A2 数据与标签**：换 **FERPlus（重标注）/RAF-DB/AffectNet**；用 **EAC(ECCV'22)**、**DMUE/标签分布学习** 把"标签噪声"从 bug 变成显式建模对象。
- **A3 范式升级**：① 离散 7 类 → **连续 Valence-Arousal**，绕开"基本情绪是否成立"的争议；② **多模态**（脸+语音+文本+生理）抗假笑/面瘫；③ 接 **CLIP / 多模态大模型** 做零样本与"出理由"的可解释推理，"小 CNN 实时初筛 + VLM 疑难复核"是有产品感的快慢双系统。
- **A4 时序**：**DFEW/FERV39k** 数据集、**Former-DFER** 时空 Transformer；轻量做 TCN/时序聚合；本项目已落地最低成本的滑窗投票。
- **A5 自监督**：**MARLIN(CVPR'23)/MAE** 在无标注人脸视频上预训练，解决"标注又贵又脏"。
- **A6 端侧**：**知识蒸馏**（大模型当老师蒸小网络）+ **INT8 量化 + ONNX/TensorRT**——本项目的轻量 CNN 正是理想的蒸馏学生/边缘载体。

### 8.2 跨场景落地（窄场景代理信号）

通用"情绪识别"做产品很难，但**换成窄场景代理信号**，空间立刻打开：

| 场景 | 可行性 | 真实信号 / 关键 |
|---|---|---|
| **驾驶舱监测 DMS** | ⭐⭐⭐⭐⭐ | 疲劳/分神(闭眼 PERCLOS、打哈欠、视线偏离)，欧盟新车强制，**最不踩伦理雷，推荐主攻** |
| 游戏/VR 虚拟形象驱动 | ⭐⭐⭐⭐ | 表情实时映射 blendshape，精度要求低、无读心包袱 |
| 远程医疗/心理筛查 | ⭐⭐⭐⭐ | 表情贫乏/微表情，须多模态+连续 V-A，仅辅助不替代诊断，门槛最高 |
| 零售/UX 体验测试 | ⭐⭐⭐ | 录像里标注"第几秒负面反应"，本项目几乎可直接用 |
| 在线教育专注度 | ⚠️ | **欧盟 AI Act 禁止个体情绪评判**，只能做匿名聚合的内容反馈 |
| 无障碍辅助 | ⭐⭐⭐ | 自闭症情绪提示、渐冻症表情交互，社会价值高 |
| 客服质检 | ⭐⭐⭐ | 语音为主表情为辅，市场成熟但红海 |

**选场景第一原则**：把 FER 当"客观代理信号 + 聚合统计 + 不声称读心"的场景就活得好（驾驶、UX、虚拟形象）；想用它"个体评判内心"的，要么违法、要么不科学、要么两者都是。

### 8.3 演进路线图与底线

| 阶段 | 关键动作 | 定位 |
|---|---|---|
| **L1 已达成** | 预训练 ResNet18 + 全套训练技巧 + 时序投票 + Grad-CAM，PrivateTest **0.660** | 优秀课程作业 / 毕设级 |
| L2 现代化 | FERPlus 标签 + 关键点融合 + 连续 V-A + 抗过拟合 | 竞赛级 |
| L3 产品化 | 选窄场景(首推 DMS/虚拟形象) + 多模态 + 蒸馏到边缘 + 合规设计 | 真实应用原型 |

**不可逾越的底线**：① 科学诚实（输出"面部表情倾向"而非"真实情绪"）；② 合规优先（职场/教育个体情绪识别欧盟已禁）；③ 以人为辅（医疗/安全场景仅辅助）；④ 偏见审计（跨肤色/年龄/文化做公平性测试）。

## 九、总结

这个项目从一版 0.567 的轻量 CNN，经过"口径对齐 + 损失/增强/优化升级 + 预训练骨干 + 时序平滑 + Grad-CAM 可解释"的系统改造，做到了 **PrivateTest 0.660 / Macro-F1 0.629**，且 disgust 过度预测被修复、模型被验证"看对了脸部区域"。**这套"分析 → 改造 → 实测 → 可解释证据"的完整闭环，比单纯一个高分更有说服力。**

再往前推，真正的杠杆不在"把 0.660 刷到 0.73"，而在**三次范式切换**：逐帧→时序、离散标签→连续 V-A、单模态→多模态/VLM 可解释；而它最现实的商业归宿，是做一个被蒸馏到边缘端的"快系统"，去服务驾驶疲劳、虚拟形象、UX 反馈这些"要代理信号、不要读心"的窄场景——技术够得着、伦理站得住、市场有人买单。绕不开的那句拷问始终在：**"表情真的等于情绪吗？"**
